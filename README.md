# 001

中周期高低位监控池与板块切换信号原型，用于把策略日报中的“科技股局部滞涨与退潮、超跌品种企稳、科创/超跌/消费高低切换”落到可运行代码。

## 设计原则

- **不用短周期股价波动直接下结论**：分类同时参考 60/120 日位置、20/60 日均线斜率、60 日回撤、相对强度、量能变化。
- **高位池看退潮风险**：高位股若出现大跌、相对强度走弱、均线斜率转负、放量下跌，会提高退潮风险分。
- **低位池看修复质量**：低位股若回撤充分、当日企稳反弹、相对强度转强、20 日斜率修复，会提高修复分。
- **切换信号看共振**：只有高位退潮风险与低位修复信号同步增强时，才提示“高位 → 低位”的中周期切换窗口。
- **支持板块内/板块间切换**：可同时比较科创内部高低切换，以及科创、超跌修复、消费等板块之间的强弱差。

## CSV 字段

示例数据见 `examples/market_snapshots.csv`。

| 字段 | 含义 |
| --- | --- |
| `symbol`, `name` | 证券代码、名称 |
| `sector`, `board` | 策略板块、交易板块 |
| `close`, `pct_change` | 收盘价、涨跌幅（小数，例如 `-0.0781`） |
| `relative_strength` | 相对强度，可使用相对全 A、科创 50 或自定义基准的标准化差值 |
| `position_60d`, `position_120d` | 60/120 日区间位置，0 为区间低点，1 为区间高点 |
| `ma20_slope`, `ma60_slope` | 20/60 日均线斜率 |
| `drawdown_60d` | 60 日最大回撤或距高点回撤 |
| `turnover_ratio`, `volume_ratio` | 换手率、量比 |

## 运行

```bash
python -m market_monitor.cli examples/market_snapshots.csv
```

输出包含：

1. 高位监控池：优先展示退潮风险高的标的。
2. 低位监控池：优先展示修复信号强的标的。
3. 中性观察池：位置居中或信号不足的标的。
4. 切换信号：包括高位到低位、板块间轮动或暂无信号。
