# A股波段涨幅-回撤空间研究（沪深300锚定）

本项目实现你提出的研究框架：
- 以 **沪深300指数** 作为趋势周期锚；
- 自动划分指数波段（趋势上行段）；
- 在每个波段内计算个股：
  - 最大上涨幅度；
  - 峰值后最大回撤（peak→trough）；
- 按涨幅阈值/分桶输出回撤统计映射：
  - `[30%, X0] [50%, X1] [80%, X2] [100%, X3] [120%, X4] [150%, X5] [200%, X6] [250%, X7] [300%, X8] [500%, X9]`。

## 目录结构

- `scripts/hs300_wave_model.py`：核心统计脚本（纯 Python 标准库，无三方依赖）。
- `data/index/000300.csv`：沪深300指数样例数据（CSV）。
- `data/stocks/*.csv`：个股样例数据（CSV，可选 `volume` 字段用于结构状态机）。
- `output/wave_summary.json`：统计输出。

## 数据格式

CSV 需至少包含以下字段：

```csv
date,close,volume
2016-01-04,3200,1000000
```

- `date`: `YYYY-MM-DD`
- `close`: 收盘价（前复权或不复权需一致）
- `volume`: 成交量（可选；若提供，则用于量能萎缩、放量破位、反向杀恐慌判定）

## 运行

```bash
python scripts/hs300_wave_model.py \
  --index-csv data/index/000300.csv \
  --stock-dir data/stocks \
  --output-json output/wave_summary.json \
  --reversal-pct 0.12
```

## 核心逻辑（实盘应用版）

1. **周期锚定（Index Regime）**
   - 使用沪深300日线构建趋势状态机；
   - 以 `reversal_pct`（默认 12%）定义趋势反转阈值；
   - 自动提取“谷底→波峰”的上行波段。

2. **个股波段测度（Stock Wave Metrics）**
   - 在每个指数上行波段中，对每只个股：
     - 以波段起点首个可交易日收盘价为基准；
     - 计算波段内 `max_gain`；
     - 计算达到峰值后至波段结束的 `max_drawdown_after_peak`。

3. **上涨空间→回撤空间映射（Rise→DD Map）**
   - 阈值统计：`max_gain >= T` 条件下的回撤均值/中位数/P75；
   - 直接输出你需要的 `rise_dd_pairs`：`[30%,X0]...[500%,X9]`（`X` 使用中位数回撤百分比）；
   - 分桶统计：`[30%,50%)...[300%,500%)...[500%,∞)`。

4. **空间层级状态机（Architecture State Machine）**
   - 将个股最大涨幅划分为：地基、承重梁、趋势立柱、黄金房体、顶楼松动、危楼出货、空中楼阁；
   - 输出 `architecture_signals`，包含当前层级、稳定性得分、实盘动作、风险位、Theil-Sen 支撑与拉黑标记；
   - 对 30%-80% 区间加入“时间风化”补丁：停留超过 20 个交易日未突破，评级下调一级；
   - 对 80%-120% 黄金房体、150%+ 危楼/泡沫段加入“放量破位”补丁：跌破历史 P75 风险位且放量，触发清仓或拉黑；
   - 对危楼/泡沫段进一步要求收盘跌破 Theil-Sen 趋势支撑，才判定切入“反向杀恐慌段”。

5. **统计模型优化（内置）**
   - 对回撤分布做 winsorize（2%~98%）抑制极端值；
   - 同时给出均值和中位数，降低偏态分布误导。

## 可继续优化（建议）

- **分层回归**：按行业、市值、流动性分层估计 `E(DD | Gain, Regime)`；
- **稳健区间**：对每个阈值做 bootstrap 置信区间；
- **状态增强**：在指数波段外引入波动率状态（低/中/高波）做双维切片；
- **交易约束**：将停牌、涨跌停可成交性纳入可实现回撤估计；
- **拉黑池复核**：对 `blacklist_symbols` 做次日可成交性、跌停封单、流动性冲击复核，避免纸面信号无法执行。

## 备注

当前仓库内置的是可运行样例数据，替换为完整 10 年 A 股数据即可产出实证统计结果。

## 危楼断裂 → 反向杀恐慌段判定

`architecture_signals` 中的 `blacklist=true` 是海选粗筛的硬过滤结果。当前实现采用四条件共振，避免单一指标误杀：

1. **空间位置**：`runup_pct >= 150`，说明个股已经进入“危楼出货/泡沫异化”高位区；
2. **风险位破坏**：`abs(current_dd_pct) >= risk_drawdown_pct`，其中 `risk_drawdown_pct` 来自历史同涨幅层级的 `dd_p75`；
3. **量能断裂**：`vol_ratio_1d_60d >= 1.5`，即当日成交量超过近 60 个交易日均量的 1.5 倍；
4. **趋势塌方**：收盘价跌破由上升段价格拟合出的 `theil_sen_support`。

同时满足以上条件时，系统输出：

- `reverse_panic=true`
- `blacklist=true`
- `action="绝对拉黑/可进入做空观察池（危楼断裂，切入反向杀恐慌段）"`

样例数据中的 `300999` 专门用于演示该判定：其最新指数波段内涨幅达到 180%，当前回撤超过历史 P75 风险位，同时放量跌破 Theil-Sen 支撑，因此进入 `blacklist_symbols`。
