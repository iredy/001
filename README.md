# Price Density Extreme Radar

这是一个 TradingView Pine Script v5 指标，用于把“价格密集区 + 2 倍标准差”落地成可监控的量价雷达。

## 指标逻辑

1. 在指定统计周期内取最高价与最低价，得到价格跨度。
2. 将价格跨度切分为多个价格区间单位。
3. 对每个价格区间逐根扫描 K 线：只要某根 K 线的 `high/low` 穿越或触碰该区间，该区间计数加 1。
4. 统计所有区间的穿越次数，穿越次数最大的价格区间定义为“价格密集区”。
5. 以密集区中轴为中心，叠加收盘价标准差，绘制 `密集区 ± 2σ` 极端警戒线。

## 实战判定闭环

当价格向下触及 `密集区 - 2σ` 时，脚本不会直接给出抄底信号，而是拆成三类状态：

- **仅雷达触发**：价格到了极端区，但量价没有确认，继续观察。
- **终极震仓确认**：价格砸穿或触碰警戒线后收回，出现放量、长下影、高收盘位置，并在确认窗口内出现需求确认。
- **冰层断裂**：价格放量宽幅跌破警戒线，收在低位、下影不足，并出现继续向下的跟随。

## 核心量价指标

- 相对成交量：`volume / sma(volume, volLen)`。
- 振幅效率：`(high - low) / ATR`。
- 收盘位置：`(close - low) / (high - low)`。
- 下影线占比：`(min(open, close) - low) / (high - low)`。
- 需求确认：确认窗口内放量阳线突破前一根高点。
- 破位跟随：确认窗口内继续跌破前一根低点并收在 `密集区 - 2σ` 下方。

## 使用方法

1. 打开 TradingView 的 Pine Editor。
2. 复制 `indicators/density_extreme_radar.pine` 的内容。
3. 保存并添加到图表。
4. 将 `统计周期 K 线数`、`价格区间数量`、`放量阈值` 调整到你的市场和周期。

> 该指标只负责把“极端位置 + 量价确认”客观化，不替代基本面、流动性、事件风险和交易纪律。
