# 001

This repository contains lightweight operational helpers and documentation for running OpenClaw sector-analysis workflows safely.

## Sector-analysis model-cost controls

Use `scripts/run_sector_analysis_env.sh` to run the existing `runsectoranalysis.py` entrypoint with model selection injected through environment variables instead of dynamic application routing.

See `docs/sector-analysis-model-env.md` for the full low-cost, environment-stable model profile design.
