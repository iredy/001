# 大江大河投资交易系统

这是一套融合芒格第一性原理哲学、宏观与产业基本面确定性、威科夫筹码博弈学（CM 行为）、江恩时空探测，以及系统性风险应对的投资交易框架。它强调先建立相对确定性的投资逻辑，再用市场行为确认买卖时机。

## 一、顶层哲学与认知基石

### 1. 投资的本质：逆人性与客观规律

- **生活的决定大于投资的决定**：抛弃对 CAPM、Beta 系数和复杂资产定价模型的机械依赖，以跨学科思维模型、基本公理、人类成就与人性弱点为中心。
- **投资的终极目标**：通过财务独立，获得精神与时间的自由。
- **大江大河 vs 漩涡礁石**：看市场要看主干趋势，包括宏观周期、产业供需与现金流折现，不纠结于日内高频波动、短期噪声或细枝末节。
- **摒弃预设**：市场不以个人意志为转移，投资者要听懂市场语言，让市场自身行为指导交易。

### 2. 第一性原理：三类真相穿透模型

在下达任何交易指令前，应穿透董事会年度或半年度工作总结与展望，提出三类核心问题：

| 真相类型 | 核心问题 | 关注重点 |
| --- | --- | --- |
| 物理 / 技术真相 | 这件事的硬边界在哪里？ | 能量密度、芯片制程、带宽、延迟、物理极限 |
| 经济真相 | 最不可动摇的经济事实是什么？ | 长期回报本质是未来自由现金流折现 |
| 人性真相 | 哪些偏好与惰性不会改变？ | 产品普适性、使用场景、TAM 与长期需求 |

## 二、宏观与微观基本面：建立相对确定性

### 1. 宏观周期与市场阶段

- **中国经济周期定位**：对标美国历史上相同经济环境与市场背景下的行业演绎规律，判断中国经济是否处于由萧条到复苏的周期阶段。
- **A 股中长期行情判断**：若宏观周期进入复苏，则确认 A 股可能处于中长期牛市或大型波段行情的起点。
- **同一周期下的核心原则**：企业内生增长才是核心，价格形态是经济周期景气程度演绎的外在表达。

### 2. 因属性施估值

| 企业类型 | 主要估值方法 |
| --- | --- |
| 成熟 / 稳定现金流企业 | DCF / DDM 贴现模型 |
| 高成长 / 应用端企业 | PS 或 PEG |
| 周期性企业 | PE 与 PB 的倒置应用 |

### 3. 多维度数据诊断与产业链地位

- **硬数据穿透**：生产规模、订单量、库存周期、市场增长率、渗透率、产能利用率、杠杆率阈值。
- **场景与护城河**：产品是商用还是家用，普适性与市场容量有多大，企业在上下游产业链中处于什么地位，护城河是深是浅。
- **交易前提**：只有界定好个股未来上涨具备相对确定性的基本面逻辑后，才进入交易层面。

## 三、交易博弈与威科夫 / 江恩集成

### 1. 筹码博弈与买卖心理非对称性

- **主力（CM）的真实定义**：没有人能够控盘一个有规模的企业。所有对企业形成同一中长期强共识的投资者，共同构成主力。
- **主力的新老更替**：专业机构和主力的行为也会因为自身筹码盈亏发生更替。
- **买入是“得到”与“多选”**：买方拥有平替标的、时点选择与分散投资的权利。
- **卖出是“失去”与“唯一”**：卖出只和一个个体发生关系，是一次性交割，也意味着彻底丧失该资产未来上涨机会。
- **筹码转移**：浮动筹码在每日盈亏波动的折磨下，从无确定性判断的散户流向坚定看好企业中长期本质的主力。

### 2. 威科夫三大法则

1. **供求关系法则**：需求大于供应则上涨，成交量通常走在价格前面。
2. **因果法则**：底部积累的“因”，决定后续波段的“果”。
3. **努力与结果法则**：成交量（努力）必须与价格波幅（结果）匹配；放量不涨可能意味着隐性供应涌出。

### 3. Spring 进场与二次测试（Test）标准

```text
大背景：上升趋势或前期强支撑区
        │
        ▼
突破支撑 / 向下假破位
        │
        ├── 供应耗尽（极小成交量）
        │       │
        │       ▼
        │   反弹时需求扩大（阳线）
        │
        └── 卖盘控制 / 供应较大
                │
                ▼
            绝不能立即利用，必须等待二次测试

二次测试（Test）铁律：
- 成交量显著缩小
- 高低价差缩小
- 波幅收缩

进场后观察：
- 若出现伴随递增成交量、持续创新高的大阳线，说明需求主导，可持有大型波段行情。
- 若没有出现，说明供应可能趁机打压，应立刻出场，摒弃预设。
```

### 4. Spring 关键判定细则

- **最佳背景**：成功率最高的 Spring 发生在上升趋势中，或前期已建立的强支撑区。
- **破位要求**：跌破支撑时必须表现为供应耗尽，即极小成交量。
- **量大突破的处理**：如果突破支撑时成交量较大，说明卖盘仍在控制市场，绝对不能立即利用。
- **完美 Test**：成交量显著缩小，高低价差变窄，波幅收缩。
- **反弹后验证**：进场后必须看到持续创新高的阳线，并伴随递增成交量；否则立刻出场。

### 5. 江恩技术探测叠加

- 在威科夫确认 CM 进入、吸筹完成，以及 Spring / Test 成立后，再结合江恩角度线与时间周期转折点进行时空对齐。
- 观察价格密集穿越区的最大 K 线数量与量能释放，作为最终交易决策依据，用于捕捉大型波段行情。

## 四、系统性下跌风险的“泄洪”策略

- **洪水爆发的解决办法是泄洪**：系统性大跌或黑天鹅来袭时，强行筑坝堵水、死扛硬顶，容易被洪峰吞没。
- **恐慌后的成交量快速萎缩**：真正的见底信号不是跌得有多深，而是在恐慌性抛盘宣泄后，成交量极快、显著萎缩。
- **卖盘真空**：当所有想卖、敢卖的筹码基本吐光后，市场进入卖盘真空。
- **顺应泄洪，等待缩量**：泄洪阶段保持现金与防守；当“恐慌后极度缩量”叠加“大周期强支撑 / Spring”时，才是重新接纳带血筹码、顺势做多的安全时刻。

## 五、终极交易心法

> 买入靠确定性与安全边际（得到与多选），卖出靠纪律与无情执行（失去与唯一）。用宏观与三类真相看大江大河，用威科夫与江恩听懂市场语言，无预设，持中守正，让市场自身的行为指导一切交易。

## 风险提示

本框架仅用于研究和复盘，不构成任何投资建议。市场存在不确定性，任何交易决策都应结合个人风险承受能力、资金期限、仓位管理与独立判断。
